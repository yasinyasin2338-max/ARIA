# ARIA Android

Native Android wrapper for the ARIA ULTRA web interface. It packages the current UI into an Android app shell.

## Important
The app still needs a reachable ARIA server URL for `/api/chat` and `/api/image`. The server-side API keys must remain on that server; never embed them in the APK.

Build with Android Studio/Gradle. The project targets Android API 36 and minSdk 26.
