# ARIA deployment

Backend: `ARIA_SERVER`
Start: `npm start`
Port: `10000` (or platform `PORT`)

Required secret:
- `OPENAI_API_KEY`

Optional:
- `ARIA_MODEL` (default `gpt-5`)
- `ARIA_IMAGE_MODEL` (default `gpt-image-1`)
- `ARIA_WEB_SEARCH=true`
- `ARIA_ACCESS_TOKEN`
- `ARIA_VIDEO_ENDPOINT`
- `ARIA_VIDEO_TOKEN`

Do not commit API keys.
